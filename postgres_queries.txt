POSTGRESQL CHEAT SHEET (WSL / Ubuntu)

==============================
CONNECT / START
==============================

Start PostgreSQL:
sudo service postgresql start

Login (recommended):
sudo -u postgres psql

Login to specific DB:
psql -U postgres -d mydb

==============================
BASIC NAVIGATION (psql)
==============================

List databases:
\l

Connect to a database:
\c mydb

Show current database:
SELECT current_database();

Exit:
\q

==============================
TABLES & SCHEMA
==============================

List tables:
\dt

Describe table:
\d tablename

List schemas:
\dn

List all objects:
\d

==============================
DATA EXPLORATION
==============================

View rows:
SELECT * FROM tablename LIMIT 10;

Count rows:
SELECT COUNT(*) FROM tablename;

Filter:
SELECT * FROM tablename WHERE status = 'active';

Sort:
SELECT * FROM tablename ORDER BY created_at DESC LIMIT 10;

==============================
CREATE / INSERT
==============================

Create table:
CREATE TABLE test (
  id SERIAL PRIMARY KEY,
  name TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

Insert data:
INSERT INTO test (name) VALUES ('Kumar');

==============================
UPDATE / DELETE
==============================

Update:
UPDATE test SET name = 'AI Architect' WHERE id = 1;

Delete:
DELETE FROM test WHERE id = 1;

==============================
USERS & ROLES
==============================

List users:
\du

Create user:
CREATE USER myuser WITH PASSWORD 'mypassword';

Grant access:
GRANT ALL PRIVILEGES ON DATABASE mydb TO myuser;

==============================
DATABASE MANAGEMENT
==============================

Create DB:
CREATE DATABASE mydb;

Drop DB:
DROP DATABASE mydb;

==============================
SYSTEM / HEALTH
==============================

Check connections:
SELECT * FROM pg_stat_activity;

Check DB size:
SELECT pg_size_pretty(pg_database_size('mydb'));

Check table size:
SELECT pg_size_pretty(pg_total_relation_size('tablename'));

==============================
FILE IMPORT / EXPORT
==============================

Import SQL file:
psql -U postgres -d mydb -f file.sql

Export DB:
pg_dump mydb > backup.sql
