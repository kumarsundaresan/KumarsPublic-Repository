==================== WSL (Windows PowerShell) ====================

Check WSL status:
wsl --status

List distros + state + version:
wsl -l -v

Start WSL / Ubuntu:
wsl
wsl -d Ubuntu

Shutdown WSL:
wsl --shutdown


==================== Ubuntu Basics ====================

Confirm WSL:
uname -a

Show IP:
hostname -I

Open folder in Windows:
explorer.exe .

Open project folder:
explorer.exe ~/smartomation

==================== PostgreSQL ====================

Check service:
service postgresql status

Start:
sudo service postgresql start

Restart:
sudo service postgresql restart

Check port:
ss -ltnp | grep 5432

Test connection:
pg_isready -h 127.0.0.1 -p 5432

Open CLI:
sudo -u postgres psql

Set password:
ALTER USER postgres WITH PASSWORD 'yourpassword';

List DBs:
\l

List users:
\du


==================== MongoDB ====================

Check service:
service mongod status

Start:
sudo service mongod start

Check port:
ss -ltnp | grep 27017

Open shell:
mongosh


==================== Node / Next.js ====================

Check versions:
node -v
npm -v
npx -v

Install Node (NVM):
nvm install --lts
nvm use --lts

Create Next app:
npx create-next-app@latest smartomation

Run app:
cd smartomation
npm run dev

Open browser:
http://localhost:3000
